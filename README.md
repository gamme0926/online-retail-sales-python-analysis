# 🛒 Online Retail Sales Analysis

## 📌 Project Overview

This project analyzes an Online Retail dataset using Python and Pandas to uncover valuable business insights. The analysis focuses on revenue performance, top\-selling products, customer purchasing behavior, and country\-level sales trends.

The project demonstrates real\-world Data Analytics skills including data cleaning, exploratory data analysis (EDA), aggregation, visualization, and business reporting.

---

## 🎯 Objectives

- Clean and prepare retail sales data
- Calculate revenue metrics
- Identify top\-performing countries
- Identify top\-selling products
- Analyze customer purchasing behavior
- Create professional visualizations
- Generate actionable business insights

## 💡 Key Insights

- United Kingdom generated the highest revenue.
- A small number of products contributed significantly to total sales.
- Customer purchasing behavior follows a highly uneven distribution.
- Revenue is strongly influenced by Quantity and Unit Price.
