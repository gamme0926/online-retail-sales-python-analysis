# 📊 Online Retail Sales Analysis

## Overview

This project analyzes an online retail dataset using Python and data analysis libraries to uncover business insights and sales trends.

The project demonstrates practical Data Analytics skills including:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Revenue Analysis
- Customer Analysis
- Product Performance Analysis
- Data Visualization

---

## Dataset

The dataset contains online retail transaction records, including:

- Invoice Number
- Product Code
- Product Description
- Quantity
- Invoice Date
- Unit Price
- Customer ID
- Country

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Git
- GitHub

---

## Data Cleaning Process

The following cleaning tasks were performed:

- Checked missing values
- Removed invalid records
- Verified data types
- Created a Revenue column

Revenue Calculation:

df["Revenue"] = df["Quantity"] \* df["UnitPrice"]

## Visualizations

The project generates the following charts:

- Top 10 Countries by Revenue
- Top 10 Products by Revenue
- Revenue Distribution Histogram
- Correlation Heatmap

---

## Key Findings

- United Kingdom generated the highest revenue.
- A small number of products contributed significantly to overall sales.
- Revenue is strongly influenced by sales quantity and product price.
- Customer spending patterns are unevenly distributed.
